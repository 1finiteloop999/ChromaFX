# ChromaFX 参数说明书

---

## 0. 先理解：参数分三层

```
第一层  方案参数（配色面板顶部）
        ── 决定"这套配色长什么样"
        ── 每次配色都要动，只有4个

第二层  粒子绑定（配色面板 Bindings 区）
        ── 决定"每个粒子从配色里拿哪个颜色"
        ── 接入新特效时配置一次，之后基本不动

第三层  Profile 参数（FireColorProfile 资产）
        ── 决定"配色的整体风格取向"
        ── 定好一次，整个项目通用
```

**一个比喻**：第三层是"调色师的习惯"，第二层是"这幅画哪里用什么颜色"，第一层是"这次画什么色调"。

---

## 1. 日常使用：只需要这 4 个

打开 `Tools → ChromaFX → Color Panel`，绝大多数时候你只动这几个：

| 参数 | 作用 | 怎么用 |
|------|------|--------|
| **Seed Color** | 主色。整套配色都从它推导 | 想要红火焰就选红色，想要蓝色魔法火就选蓝色 |
| **Harmony Mode** | 配色模式，决定"跳色在色轮上的位置" | 见下方说明 |
| **Value Contrast** | 明暗对比强度 | 觉得画面发灰→调高；觉得太刺眼→调低 |
| **Harmony Strength (β)** | 颜色向"标准和谐位置"靠拢的程度 | 一般 0.7–0.9，不确定就别动 |

### Harmony Mode 四种模式怎么选

| 模式 | 视觉效果 | 适合 |
|------|---------|------|
| **Analogous 类比** | 统一、柔和、安全 | 自然篝火、治疗光效 |
| **Complementary 互补** | 强对比、有张力 | 战斗特效、爆炸 |
| **Triadic 三角** | 多个颜色都能区分开 | 元素混合、复杂技能 |
| **Split-Complementary 分裂互补** | 有张力但比互补柔和 | 大多数游戏特效的安全选择 |

> **重要**：互补色**不等于**更好看，它只是"对比更强"。学术上和谐度最高的通常是类比色。选哪个取决于你想要"统一"还是"张力"。

### Value Contrast 直观理解

它控制**最亮的部分和最暗的部分差多少**：

- 调到 **0**：所有层的明暗都挤在一起 → 柔和、朦胧、也容易糊成一片
- 调到 **0.5**：正常
- 调到 **1**：核心非常亮、暗部非常暗 → 层次分明、有冲击力

**如果你觉得特效"灰灰的没精神"，第一个该调的就是这个。**

## 2. 接入新特效：配置绑定

每个粒子层需要回答三个问题，就是绑定的"三轴"：

### 轴1：Color Family（从哪条颜色曲线取色）

| 族 | 是什么 | 用在哪 |
|----|--------|--------|
| **Primary** | 主色系。从"亮白热"到"主色"到"暗色" | 火焰主体、内焰、火星、辉光——**大部分层都用它** |
| **Accent** | 跳色系。色相在主色的对面（由配色模式决定） | 需要强调、跳出来的小元素。**自然特效经常一个都不用** |
| **Neutral** | 中性系。几乎没有颜色，只有明暗 | 烟雾、灰尘、影子 |

> 常见误区：以为"跳色层就该用 Accent"。实际上自然篝火的火星应该是 **Primary**——它是热的，不是异色的。乱用 Accent 正是"单看配色挺好，用上去很怪"的主因。

### 轴2：Tone Position（在曲线上取多亮/多暗）

一个 0 到 1 的滑条：

```
0.0 ──────────── 0.5 ──────────── 1.0
最亮/最热        主色本身          最暗
（接近白）                        （接近黑）
```

- **0.05–0.20**：内焰、核心、刚出生的火星
- **0.40–0.50**：火焰主体（0.45 正好等于你选的主色）
- **0.60–0.75**：过渡层、次要火苗
- **0.85–0.95**：烟雾、暗部

**这个值取代了旧版"列表顺序"**——现在两层想拉开深浅，就给不同的 tone，跟它们在列表里的位置无关。

### 轴3：Temporal Profile（一生中颜色怎么变）

| 剖面 | 行为 | 用在哪 |
|------|------|--------|
| **Constant** | 颜色不变，只有透明度动画 | 辉光、光晕 |
| **Cooling** | 出生偏热亮 → 本体色 → 熄灭变暗（像余烬冷却） | 火焰、火星、余烬 |
| **Dimming** | 没有出生高亮，只是逐渐变暗 | 暗色火苗、已经很暗的层 |
| **SmokeFade** | 微微亮起后变暗 | 烟雾 |

### 每条绑定的其他参数

| 参数 | 作用 | 什么时候动 |
|------|------|-----------|
| **Temporal Strength** | 上面那个变化有多剧烈 | 火星要"烧透"就调高，主体火焰保持低一点 |
| **Energy Scale** | 这层有多亮（HDR 发光强度倍率） | **某层太暗/太亮时调它**，是最常用的绑定参数 |
| **Write Policy** | 写入方式 | 一般保持 `FullPipeline`；不参与配色的层选 `Excluded` |
| **Visual Weight** | 仅用于评价指标，**不影响画面** | 基本不用动 |

### ⚠️ Energy Scale 用于微调，不用于修正素材错误

每层最终亮度 = **素材材质的 HDR 强度（基线）× Energy Scale**。基线是"这个素材本来有多亮"，Energy Scale 是"在此基础上再调多少"。

- **正常范围：0.5 ~ 2.0**。这是微调。
- **需要 3 倍以上才正常** → 说明**素材本身的强度值错了**，应该去改素材，而不是靠这里长期补偿。

典型情况：某层在原素材里是按"淡淡的白雾"调的（HDR 只有 0.4），但在 ChromaFX 里它被指派为主体层（MAIN）——两种定位对亮度的要求差一个数量级。工具会忠实保留基线（这是刻意设计，为了不破坏 Bloom 层级），所以它也忠实保留了这个错误。

**改素材的正确顺序**（跳步会把染色结果烤进基线）：

```
1. 面板 Restore Original      ← 回到基线干净状态
2. 改材质的 _MainColor        ← 必须保持纯灰度 r=g=b；
                                 HDR 选择器 Intensity 1.0 = 2.0，1.58 = 3.0
3. 面板 Recapture Baseline    ← 新值成为基线
4. Apply，并把该层 Energy Scale 改回 Inherit
```

**怎么发现这类问题**：面板 Fitness 区的 **Energy-order inversions** 就是干这个的。它会指名两层，例如
`Fire_Smallfire(tone 0.60) 比 Fire_Base(tone 0.45) 亮 5.0×` —— 色调位置说前者更暗，实际亮度却高 5 倍，这就是素材能量与角色定位冲突的信号。

> **Inherit 按钮**：勾上表示"用 Profile 里的默认值"，旁边灰字会显示继承到的具体数字。取消勾选才能单独设定这一层。

## 3. 风格微调：Profile 里真正该动的 6 个

打开 `FireColorProfile` 资产。里面有 30 个参数，但**日常只需要关心这 6 个**：

| 参数 | 作用 | 调大 | 调小 | 建议值 |
|------|------|------|------|--------|
| **hotLightnessDelta** | 曲线热端有多亮 | 核心更白更亮 | 核心保留更多颜色 | 30–45 |
| **hotChromaScale** | 热端保留多少颜色 | 热端仍然鲜艳 | 热端趋向白热 | 0.4–0.7 |
| **deathTravelTowardDark** | 粒子熄灭时走多远 | 火星会彻底烧成暗色 | 熄灭得含蓄 | 0.5–0.9 |
| **neutralChromaCap** | 烟雾最多能带多少颜色 | 烟雾偏色 | 烟雾更纯灰 | 0–8 |
| **deathAlphaCoupling** | 颜色变暗时透明度同步减多少 | 暗色粒子自动淡出 | 暗色粒子保持实心 | 0.4–0.7 |
| **startValueJitter** | 每颗粒子的亮度随机差异 | 颗粒感强、有杂色 | 整齐划一 | 0.1–0.25 |

### 这 6 个的调法

**火焰核心不够"白热"** → `hotLightnessDelta` 往 42 调，`hotChromaScale` 往 0.4 调

**火星没有"烧透"的感觉** → `deathTravelTowardDark` 往 0.8 调

**烟雾发彩、不干净** → `neutralChromaCap` 往 0–3 调

**暗部像贴纸/黑纸片** → `deathAlphaCoupling` 往 0.7 调

**特效看起来太"塑料"、太整齐** → `startValueJitter` 往 0.25 调

## 4. 完整参数字典

### 4.1 色调曲线 · 热端

| 参数 | 说明 |
|------|------|
| `hotLightnessDelta` | 热端比基准色亮多少（L\* 单位，0–60）。受 Value Contrast 缩放 |
| `hotChromaScale` | 热端彩度倍率。小于 1 会趋向白热 |
| `hotHueDrift` | 热端向暖色偏移的最大角度。让高光偏黄橙，符合火焰的物理直觉 |
| `lchWarmAnchor` | 暖色锚点的色相角。**注意这是 LCh 色相角，不是 HSV 色相**，85° 约等于黄橙。不建议改 |

### 4.2 色调曲线 · 暗端

| 参数 | 说明 |
|------|------|
| `darkLightnessDelta` | 暗端比基准色暗多少（负值） |
| `darkChromaScale` | 暗端彩度倍率 |
| `darkHueDrift` | 暗端向中性色相收敛的角度。让所有颜色在变暗时趋于统一，避免暗部花 |

### 4.3 明度对比映射

| 参数 | 说明 |
|------|------|
| `contrastScaleMin` / `Max` | 面板上的 Value Contrast 滑条从 0 到 1 时，实际缩放倍率的范围。默认 0.6–1.4 |

### 4.4 分族彩度规则

| 参数 | 说明 |
|------|------|
| `primaryChromaFloor` | 主色系采样时的彩度下限，防止渐变中途"穿过灰色"变脏 |
| `accentChromaFloor` | 跳色系同上 |
| `neutralChromaFloor` | 中性系的彩度下限，**应保持接近 0**，否则烟雾会变成脏彩色 |
| `neutralChromaScale` | 中性基准彩度 = 主色彩度 × 此值 |
| `neutralChromaCap` | 中性基准彩度的绝对上限。烟雾偏色时调这个 |
| `neutralLightnessDelta` | 中性基准比主色基准暗多少 |

> 彩度下限有个保护：它永远不会超过基准色本身的彩度。所以你选一个灰色作主色时，系统不会强行给它加彩。

### 4.5 跳色

| 参数 | 说明 |
|------|------|
| `accentBetaBoost` | 跳色投影时 β 的加成倍率。跳色可以比其他颜色更贴近标准对比位置 |
| `accentBlendToPrimary` | 把跳色往主色混合，柔化对比。**这是色差参数，不是面积参数**。自然篝火没有 Accent 绑定，此值不生效 |
| `accentBudget` | 跳色允许占的视觉比例上限。**只用于面板告警，不改变画面** |

### 4.6 生命周期

| 参数 | 说明 |
|------|------|
| `birthTravelTowardHot` | 出生色向热端走多远（占剩余距离的比例） |
| `deathTravelTowardDark` | 熄灭色向暗端走多远 |
| `birthEndTime` | 出生段在生命周期的几成结束（0.15 = 前 15%） |
| `deathStartTime` | 熄灭段从几成开始（0.70 = 后 30%） |
| `deathAlphaCoupling` | 熄灭色越暗，透明度同步下降越多。防止出现"黑色纸片" |

> **"走多远"是按剩余距离算的**：一个已经在 tone 0.15（很热）的火星几乎无法更热，但有很长的距离可以变暗——这正是余烬该有的行为，不需要特殊设置。

### 4.7 默认值（供绑定继承）

| 参数 | 说明 |
|------|------|
| `defaultCoolingStrength` / `Dimming` / `SmokeFade` | 三种时间剖面的默认强度，绑定设为 Inherit 时用它 |
| `defaultPrimaryEnergy` / `Accent` / `Neutral` | 三个色族的默认能量倍率。这只是粗略默认值，具体层的亮度差异主要靠**素材原本的 HDR 强度**承担 |

### 4.8 其他

| 参数 | 说明 |
|------|------|
| `startValueJitter` | 每颗粒子的亮度随机范围。只对原本是单色的 StartColor 生效；原本就是随机区间的层不会叠加 |
| `Material-Only Mode`（面板上） | 只影响 Write Policy 为 MaterialOnly 的绑定，是做对照实验用的，日常不用管 |

## 5. 症状 → 调哪个（速查表）

| 你看到的问题 | 先调这个 | 再考虑 |
|------------|---------|-------|
| 整体发灰、没精神 | Value Contrast ↑ | hotLightnessDelta ↑ |
| 核心不够亮、没有白热感 | 该层 Energy Scale ↑ | hotChromaScale ↓ |
| 某一层太亮/太暗 | 该层 Energy Scale | 该层 Tone Position |
| 火星没有"烧透"消失的过程 | deathTravelTowardDark ↑ | 该层 Temporal Strength ↑ |
| 烟雾带颜色、显脏 | neutralChromaCap ↓ | 确认该层是 Neutral 族 |
| 烟雾在发光 | 该层 Energy Scale ↓ | 面板会有 Glowing neutral 告警 |
| 暗色粒子像黑色贴纸 | deathAlphaCoupling ↑ | 该层 Tone Position ↓ |
| 颜色好看但整体很怪 | 检查是否误用了 Accent 族 | accentBlendToPrimary ↑ |
| 层次太乱、看不出主次 | 检查面板的 Energy-order inversions | 调整冲突层的 Tone 或 Energy |
| 粒子太整齐、像塑料 | startValueJitter ↑ | — |

## 6. 不建议改动的参数

| 参数 | 原因 |
|------|------|
| `lchWarmAnchor` | LCh 色相角与直觉不符，改了容易得到意外结果 |
| `contrastScaleMin` / `Max` | 改了会让 Value Contrast 滑条的手感在项目中期发生变化 |
| `birthEndTime` / `deathStartTime` | 时序结构，改动会同时影响所有层 |
| `accentBudget` | 只影响告警阈值，不改变画面 |
| 扇区宽度、Fitness 权重 | 这些是文献常数（Matsuda 模板宽度等），写死在代码里。改动它们等于改变理论依据，需要在论文中说明 |

另外，**三个色族的基准色由算法决定，Profile 里没有能改它们的参数**——主色 = 你输入的种子色，跳色 = 和谐模板投影结果，中性 = 主色色相加极低彩度。这是刻意的设计：保证"跳色来自色轮理论"这一点在参数层面无法被违反。

---

## 7. 推荐调参顺序

新接一个特效时，按这个顺序走，不要跳步：

```
1. 生成绑定，给每层定 Family / Tone / Temporal
   ↓ 先只看结构对不对，别管好不好看
2. 选一个主色，把 Value Contrast 拉到 0.5
   ↓ 现在应该已经"能看"了
3. 逐层调 Energy Scale，把亮度层级理顺
   ↓ 这一步解决 80% 的"发灰/发闷"问题
4. 微调各层 Tone Position，拉开明暗层次
   ↓ 参考面板的 Energy-order inversions 告警
5. 最后才动 Profile 里那 6 个风格参数
   ↓ 这一步是定"整个项目的风格"，不是救某一个特效
6. 换 2–3 个不同主色验证，确认换色后依然成立
```

> **第 5 步之前不要动 Profile**。Profile 是全局的，用它去救单个特效的问题，会把其他特效一起带偏。
